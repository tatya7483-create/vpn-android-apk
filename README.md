# VPN Share — раздача VPN через USB-модем

Совместное использование VPN (Hiro VPN и любых других) с телефона Android на ПК Windows через USB-кабель.

## Как работает

На **телефоне** работает прокси-сервер (SOCKS5 + HTTP), который принимает соединения с USB-интерфейса. Исходящие соединения прокси автоматически идут через системный VPN (Hiro), так как Android по умолчанию направляет весь трафик приложений через активный VpnService. DNS резолвится на телефоне (утечек DNS нет).

На **ПК** программа подключается к этому прокси и пускает через него трафик. Два режима:

- **Системный прокси** — настраивает системные настройки прокси Windows. Подходит для браузеров и программ, которые уважают системный прокси.
- **Полный туннель** — создаёт виртуальный TUN-адаптер (Wintun) и заворачивает ВЕСЬ трафик (TCP + UDP) через прокси. Ничего не утекает мимо VPN. Требует прав администратора.

## Требования

- **Телефон:** Android 7.0+ (API 24), Hiro VPN или любой другой VPN-клиент, включённый USB-модем
- **ПК:** Windows 10/11 x64
- **Кабель USB** (не Wi-Fi!)

## Установка и запуск

Скачайте последний релиз со страницы [Releases](../../releases).

### Шаг 1 — Телефон

1. Установите `VpnShare.apk` на телефон (разрешите установку из неизвестных источников).
2. **Важно:** включите VPN (Hiro) на телефоне.
3. Включите **USB-модем** в настройках Android (Настройки → Сеть и Интернет → Точка доступа и модем → USB-модем).
4. Подключите телефон к ПК кабелем USB.
5. Откройте приложение **VPN Share**.
6. Нажмите **«Запустить»**.
   - Если увидите предупреждение «VPN не включён», запустите VPN и нажмите «Запустить» ещё раз.
   - Разрешите уведомления и работу в фоне.
   - Рекомендуется отключить оптимизацию батареи для приложения (появится запрос).
7. В приложении отобразится **IP телефона** (например, `192.168.42.129`). Он понадобится ПК.
8. Нажмите **«Проверить VPN»** — должен показаться IP и страна VPN-сервера.

### Шаг 2 — ПК

1. Создайте папку (например, `C:\VpnShare\`) и положите в неё **оба файла**:
   - `VpnShare.exe`
   - `wintun.dll`
2. **Для системного прокси:** просто запустите `VpnShare.exe`.
3. **Для полного туннеля:** кликните правой кнопкой → «Запуск от имени администратора», затем в меню трея выберите «Режим: полный туннель».
4. Откройте на ПК браузер и зайдите на сайт проверки IP (например, [2ip.ru](https://2ip.ru) или [whoer.net](https://whoer.net)). IP должен быть VPN-ный, не вашего оператора.
5. Для выхода — иконка в трее → Выход. Все настройки автоматически откатываются.

### Консольная версия

`VpnShare-console.exe` — версия без иконки в трее, с логами в консоль:

```cmd
:: Системный прокси (по умолчанию)
VpnShare-console.exe

:: Полный туннель
VpnShare-console.exe -mode full

:: Указать IP телефона вручную (если автоопределение не сработало)
VpnShare-console.exe -phone 192.168.42.129

:: Справка
VpnShare-console.exe -h
```

## Проверка критериев

✅ **Критерий успеха:** если на телефоне включён Hiro VPN, запущено приложение, а на ПК запущена программа — сайт проверки IP показывает VPN-ный IP/страну.

❌ **Если VPN на телефоне выключен:** приложение на телефоне показывает «VPN выключен», а программа на ПК не подключится (или покажет ошибку).

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Телефон не найден | Убедитесь, что USB-модем включён; подождите 10 секунд; укажите IP вручную через `-phone` |
| SOCKS5 прокси недоступен | Проверьте, что нажали «Запустить» в приложении на телефоне |
| Полный туннель выдаёт ошибку | Запустите от имени администратора; проверьте что `wintun.dll` лежит рядом с exe |
| После выхода пропал интернет | Откройте командную строку от админа и выполните: `netsh winhttp reset proxy` и `route delete 0.0.0.0 10.0.99.1` |
| Некоторые программы не ходят через прокси | Используйте режим полного туннеля |
| DNS не резолвится | В режиме полного туннеля DNS принудительно идёт через прокси; убедитесь что VPN на телефоне работает |

## Порты

- **SOCKS5 (TCP + UDP):** порт `1080` на USB-интерфейсе и 127.0.0.1
- **HTTP proxy:** порт `8080` на USB-интерфейсе и 127.0.0.1

Прокси принимает соединения **только** с интерфейса USB-модема и с 127.0.0.1 (с других интерфейсов не принимает).

## Безопасность

- Исходящий трафик идёт через системный VPN на телефоне (так как Android направляет все соединения приложений через активный VPN).
- DNS-запросы резолвятся на телефоне средствами Android (через VPN).
- Прокси не слушает на Wi-Fi/мобильном интерфейсе — только на USB и localhost.
- В режиме полного туннеля нет утечек DNS: все DNS-запросы перехватываются и отправляются через SOCKS5 на телефон.

## Сборка из исходников

### Android APK

```bash
cd android
gradle assembleRelease
```

APK будет в `app/build/outputs/apk/release/`.

### Windows exe

На Windows (или из Linux с кросс-компиляцией):
```bash
cd pc
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -ldflags "-s -w -H windowsgui" -o VpnShare.exe .
```

Также необходим `wintun.dll` (скачать с [wintun.net](https://www.wintun.net/)).

## Структура проекта

```
├── android/          # Android-приложение (Kotlin)
│   └── app/src/main/java/com/vpnshare/tether/
│       ├── MainActivity.kt      # Экран с кнопками Старт/Стоп
│       ├── ProxyService.kt      # Foreground-сервис с прокси
│       ├── Socks5Proxy.kt       # SOCKS5 сервер (TCP+UDP)
│       ├── HttpProxy.kt         # HTTP proxy сервер
│       ├── VpnDetector.kt       # Проверка VPN и внешнего IP
│       └── NetworkUtils.kt      # Поиск USB-интерфейса
├── pc/               # Программа для Windows (Go)
│   ├── main.go                # Точка входа, CLI
│   ├── core/
│   │   ├── app.go             # Управление режимами, автопереподключение
│   │   ├── sysproxy_windows.go  # Системный прокси Windows
│   │   ├── fulltunnel.go      # Полный туннель Wintun + tun2socks
│   │   ├── tcp_tracker.go     # TCP relay через SOCKS5
│   │   ├── udp_tracker.go     # UDP relay через SOCKS5
│   │   ├── fakedns.go         # Поддельный DNS для предотвращения утечек
│   │   ├── netconfig_windows.go # Настройка IP/маршрутов TUN
│   │   └── wintun_loader.go   # Загрузка wintun.dll
│   ├── proxy/socks5.go        # SOCKS5 клиент
│   ├── discovery/gateway.go   # Поиск телефона на USB-адаптере
│   └── ui/tray.go             # Иконка в трее
└── .github/workflows/build.yml  # Сборка в GitHub Actions
```

## Ответственность

Используйте на свой страх и риск. Программа изменяет системные настройки прокси и маршрутизации Windows. При корректном завершении (через «Выход» или Ctrl+C) все настройки автоматически восстанавливаются.
